
# Primary Sources and Research References

This directory documents the sources used by the
Gaarriye Somali Poetry Meter Analyzer.

## 1. Primary Authority

Gaarriye's original publications are the primary
authority for reconstructing his metrical system.

## 2. Source Register

Each source must record:

- Source ID
- Full title
- Author
- Publication year
- Edition
- Page number
- Original text or diagram
- Relevant metrical concept
- Verification status

## 3. Evidence Classification

- VERIFIED: Confirmed directly against the source.
- NEEDS_REVIEW: Requires further examination.
- UNVERIFIED: Not yet confirmed.
- CONFLICTING: Sources or interpretations disagree.

## 4. Research Sources

Researchers' interpretations must be recorded
separately from Gaarriye's original rules.

## 5. Important Principle

Never attribute a researcher's interpretation
or an AI-generated proposal to Gaarriye without
direct supporting evidence.

Preserve original quotations, page references,
diagrams and their verification history.
