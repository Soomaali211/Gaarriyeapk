# Source Review Checklist

- [ ] The original file is present and opens correctly.
- [ ] The source is classified as primary or secondary correctly.
- [ ] Author, title, publication, issue/date, and edition are checked against the source itself.
- [ ] Printed page number is distinguished from PDF/image page index.
- [ ] The cited page or diagram is legible.
- [ ] Any transcription has been compared visually with the original.
- [ ] Unreadable or missing portions are marked; nothing is guessed.
- [ ] A stable source ID and exact file path are assigned.
- [ ] Reviewer and review date are recorded.
- [ ] Conflicts with other sources are documented, not silently resolved.

A source record alone does not prove a metrical rule.
