
# Gaarriye Metrical Rules Registry

This directory contains the formal registry of
Gaarriye's metrical rules.

## Rule Authority

Gaarriye's original publications are authoritative.
Research interpretations and AI proposals must
remain separate from verified rules.

## Rule Status

Every rule must have one of these statuses:

- VERIFIED
- NEEDS_REVIEW
- UNVERIFIED
- CONFLICTING
- PROPOSED

Only VERIFIED rules may be executed in strict mode.

## Rule Record Requirements

Each rule must include:

1. Unique rule ID
2. Rule name
3. Poetry genre
4. Formal description
5. Metrical structure
6. Conditions and exceptions
7. Primary source
8. Exact page reference
9. Evidence or quotation
10. Verification status
11. Reviewer and review date
12. Rule version

## Genre Coverage

The registry will cover:

- Jiifto
- Gabay
- Guurow
- Geeraar
- Baarcaddaha
- Saarka
- Heesta Kabadaha
- Heesta Xerta
- Heesta Carruurta
- Herimaahee Hanna Haybsan

## Strict Analysis Policy

- Do not execute unverified rules.
- Do not invent metrical patterns.
- Do not silently resolve conflicting evidence.
- Preserve exceptions and alternative readings.
- Do not classify non-conforming poetry as invalid
  Somali poetry.

## Important

This registry is initially a structural framework.
It does not claim that all listed genres or rules
have been fully verified.
