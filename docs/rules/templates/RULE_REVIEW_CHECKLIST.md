# Rule Verification Checklist

- [ ] The rule has a unique stable ID and explicit class.
- [ ] If classified `GAARRIYE_PRIMARY`, direct Gaarriye primary evidence is present.
- [ ] Exact source, printed page, digital page, and diagram are recorded.
- [ ] Quotation/transcription has been checked against the original image.
- [ ] The rule's interpretation is separated from the source's literal wording.
- [ ] Conditions and exceptions are documented.
- [ ] Conflicting diagrams/readings are recorded as conflicts.
- [ ] Positive examples are sourced and checked.
- [ ] Negative examples are sourced or explicitly marked as test hypotheses.
- [ ] Ambiguous examples are retained as ambiguous.
- [ ] Independent reviewer and review date are recorded.
- [ ] Regression tests are prepared before activation.
- [ ] Only then may the status be considered for `VERIFIED`.

Never infer a pattern from a genre name or from an unclear diagram.
